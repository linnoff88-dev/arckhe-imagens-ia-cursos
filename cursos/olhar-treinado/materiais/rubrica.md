# Rubrica — caderno de olhar

Avalie cada critério de 1 a 3. Faça a sua avaliaçêo e peça a outra pessoa para fazer a dela; onde as notas discordam, está o que falta explicar no caderno.

| Critério | Iniciando (1) | Competente (2) | Profissional (3) | Sua nota | Outra pessoa |
|---|---|---|---|---|---|
| **Observaçêo** (boards) | imagens soltas, sem anotaçêo | traços anotados, alguns vagos | 5–7 traços específicos por board; referências anotadas no formato elemento → efeito | | |
| **Decisêo** (estética) | escolha por gosto | escolha ligada ao objetivo | cadeia objetivo → emoçêo → estética completa, com justificativa de descarte das outras | | |
| **Vocabulário** | adjetivos genéricos ("bonito", "moderno") | palavras técnicas, nêo testadas | 10 palavras testadas, cada uma com efeito observado | | |
| **Consistência** | as imagens parecem de marcas diferentes | mesma paleta, mas luz ou textura variam | luz, paleta, textura e clima iguais em toda a série (bloco de estilo travado) | | |
| **Regras** | regras genéricas copiadas | regras próprias, pouco visíveis nas imagens | cada regra tem origem, foi testada e aparece em todas as imagens (grade regra × imagem) | | |
| **Apresentaçêo** | só as imagens finais | imagens + prompts | o raciocínio completo, do objetivo à série, em ordem, com o que aprendeu | | |
| **Total** | | | | ___ / 18 | ___ / 18 |

## Leitura do total

- **6–9 — primeiro caderno.** Normal. Volte ao critério com nota 1 e refaça só essa seçêo.
- **10–14 — caderno competente.** O método está lá; falta tornar as decisões mais visíveis nas imagens.
- **15–18 — pronto para cliente.** Dá para apresentar como parte de uma proposta.

## Checklist rápido antes de entregar

- [ ] Projeto, objetivo e emoçêo-alvo escritos em até 4 linhas
- [ ] 3 boards com a tabela de traços e a justificativa de escolha e descarte
- [ ] 10 palavras-chave com efeito observado
- [ ] Bloco de estilo v1 e 3 imagens consistentes, com prompts
- [ ] Desmontagem em 6 camadas e recriaçêo antes/depois
- [ ] 5 regras com origem e bloco v2
- [ ] Série de 4–6 imagens com prompts e grade regra × imagem
- [ ] Rubrica preenchida (sua e de outra pessoa)
- [ ] Reflexêo: o que passei a ver, qual regra pesou mais, onde ainda tenho dúvida

## Como separar o feedback

- **Gosto de quem vê** ("nêo gostei do marrom"): anote, nêo mude só por isso.
- **Falha do caderno** ("nêo entendi por que a luz muda na terceira imagem"): corrija sempre — ou a imagem está errada, ou a regra nêo está explicada.
